# Esempio Pratico: Ottimizzazione "Scrivi un piano marketing"

## 📌 Input Originale (Generico)

```
Scrivi un piano marketing
```

**Problemi rilevati:**
- ❌ Task troppo vago
- ❌ Nessun contesto (prodotto? target? budget?)
- ❌ Nessun vincolo (lunghezza? focus? timeline?)
- ❌ Formato output non specificato
- ❌ Success criteria assenti

**Score iniziale stimato:** 20/100

---

## ✅ Output Ottimizzato (7 Tecniche Pareto Applicate)

```

- Segmento: PMI italiane tech-forward, 20-200 dipendenti

- Competitor diretti: Monday.com, Asana, ClickUp

**Budget & Resources:**
- Budget marketing totale: €80,000 primi 6 mesi
- Team: 1 Marketing Manager, 1 Content Creator, €15k budget ads
- Canali attuali: website basic, LinkedIn company page (300 followers)
</context>

<constraints>

- Focus su primi 90 giorni post-launch (Q3 2026)

**Vincoli:**
- No TV/radio (budget insufficiente)

- B2B professionale ma approachable

</constraints>

   - Breakdown per canale (ads, content, tools, etc.)
   - Reserve per imprevisti (10-15%)

7. **Measurement & Optimization**
   - Dashboard KPI (weekly review)
   - A/B test plan (cosa testeremo?)
   - Decision triggers (quando pivot su un canale?)
</instructions>

<thinking_notes>
Prima di rispondere, ragiona step-by-step:

1. **Verifica coerenza:** Budget, team, timeline sono realistici insieme?
2. **Prioritization:** Con 2 persone e €80k, focus su 3 canali max, non 10
3. **PMI italiane B2B:** LinkedIn + Content + Community > Instagram/TikTok

5. **Metriche:** Ogni tattica deve linkare a KPI specifico misurabile
```

## 💡 Key Learnings

### What Made the Difference:

1. **Context is King** (+30% accuracy)
   - Fornire prodotto, target, budget, competitor
   - Da "piano marketing generico" a "piano questo prodotto specifico"

2. **Constraints Drive Quality** (-31% errori)
   - Timeline, budget, team size → forcing prioritization
   - "Max 3 canali" > "tutti i canali possibili"

3. **Structure Enables Consistency** (+20% adherence)
   - XML tags + template output
   - Ogni run genera stesso formato, easy to compare/iterate

4. **Uncertainty Handling** (hallucination mitigation)
   - "Se dati mancano, segnala invece di inventare"
   - Crea trust, permite human-in-loop dove serve

### Applicabile ad Altri Task:

Stesso pattern funziona per:
- "Scrivi proposta commerciale" → need cliente context, requirements
- "Crea strategia social" → need brand, audience, goals
- "Analizza dati vendite" → need actual data, metrics to track
- "Scrivi job description" → need role, company, team, expectations

**Formula Universale:**
```
Generico Task → +Context +Constraints +Structure +Examples = Specific Actionable Output
```
